# راهنمای واژگان و قواعد ترجمه — ووهِد فارسی

> هدف: ترجمه‌ای که برای گیمر ایرانی «آشنا» باشد، نه یک ترجمه تحت‌اللفظی عجیب و گیج‌کننده.
> این سند مرجع رسمی همه متن‌های سایت (دیتابیس، اخبار، توضیحات و نظرات) است.

## قانون طلایی

**همه‌چیز را ترجمه نکن؛ اصطلاحات را همان‌طوری به کار ببر که گیمرهای ایرانی تلفظ می‌کنند.**

اگر یک گیمر ایرانی جمله‌ای از این سایت را بلند بخواند، باید دقیقاً مثل حرف‌زدن در گیلد یا گروه تلگرامی‌اش звуч کند.

## ۲. اصطلاحاتی که هرگز ترجمه نمی‌شوند (به انگلیسی می‌مانند)

این واژه‌ها در متن فارسی **به خط لاتین** نوشته می‌شوند، چون گیمر ایرانی همین‌طور استفاده‌شان می‌کند:

- **نقش‌ها:** tank، heal / healer، DPS، support
- **نبرد:** crit، dodge، parry، block، hit، miss، aggro، threat، taunt، kiting، AoE، CC، burst، proc، debuff
- **گیم‌پلی:** loot، drop، respawn، buff، nerf، cooldown (CD)، channel، cast، interrupt، pull، wipe، reset
- **اجتماعی:** gیلد، main، alt، twink، grind، farm، spot، PTR، patch

## ۵. قاعده نام مکان‌ها

```
[نوع جغرافیایی ترجمه‌شده] + [نام خاص آوانگاری]
```

- Elwynn Forest → **جنگل الون** (نه «جنگلِ جنگل»!)
- Arathi Highlands → **دشت‌های آراسی**
- Burning Steppes → **دشت‌های سوزان**
- Un'Goro Crater → **دهانه اون‌گورو**
- Eastern Plaguelands → **اراضی طاعون‌زده شرقی**
- Stranglethorn Vale → **دره استرنگل‌تورن**

کلمه «سرزمین» فقط برای continent: Eastern Kingdoms = **شرق‌سرزمین**، Kalimdor = **کالیمدور** (آوانگاری).

## ۶. قواعد نوشتاری

1. **اعداد** در UI با ارقام فارسی (۱۲۳)؛ مقادیر خام دیتابیس انگلیسی — تبدیل در لایه نمایش.
2. **تاریخ‌ها** شمسی (تقویم هجری شمسی با `fa-IR`).
3. **نیم‌فاصله (ZWNJ)** رعایت شود: می‌شود، آیتم‌ها، دستاوردها.
4. **نام انگلیسی** هر موجودیت در فیلد `nameEn` ذخیره و در صفحه جزئیات زیر نام فارسی نمایش داده می‌شود — تا کاربر بتواند در ویکی‌های دیگر هم جستجو کند.
5. **نظرات کاربران** با لحن گیمی نوشته می‌شوند: «این باس رو با tank خوب و heal منظم به راحتی می‌شه کشید».
6. **اخبار** لحن خبری-گیمی دارند؛ اسم قهرمان‌ها و باس‌ها آوانگاری، اصطلاحات انگلیسی می‌مانند.
